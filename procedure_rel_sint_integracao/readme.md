Este diretório contém o script PL/SQL (linguagem procedure Oracle) de uma procedure desenvolvida para gerar um relatório com dados do histórico de uma rotina de integração entre sistemas.

O histórico da integração é armazenado em tabelas de um banco de dados Oracle. A procedure consulta esses dados, realiza a análise das informações e gera um relatório em HTML, formatado com CSS, que é encaminhado por e-mail aos responsáveis.

O relatório tem como objetivo facilitar o acompanhamento da execução da integração, a análise de seu desempenho e a identificação de possíveis falhas ou inconsistências.

This directory contains the PL/SQL script (Oracle procedure language) for a procedure developed to generate a report with historical data from a system integration routine.

The integration history is stored in tables of an Oracle database. The procedure queries this data, analyzes the information, and generates an HTML report, formatted with CSS, which is sent by email to those responsible.

The report aims to facilitate the monitoring of the integration execution, the analysis of its performance, and the identification of possible failures or inconsistencies.
